🐛 TROUBLESHOOTING RAPIDE

Service Python ne démarre:
  → Lire python_service/README.md
  → Vérifier Python 3.7+ installé
  → Réinstaller dépendances

Erreur "No module named 'dlib'":
  → pip install --force-reinstall dlib
  → Sur Windows: installer Visual Studio Build Tools

Caméra ne fonctionne pas:
  → Autoriser accès caméra dans navigateur
  → Tester sur HTTPS en production
  → Vérifier permissions système

Reconnaissance ne marche pas:
  → Vérifier http://localhost:5000/health
  → Vérifier logs: tail -f var/log/dev.log
  → Tester API avec Postman
